# cvmfs_release

CVMFS release management for the SHiP software stack.

Repository: [ShipSoft/cvmfs_release](https://github.com/ShipSoft/cvmfs_release)
(archived — kept for reference)

Its changelog covers the CVMFS releases up to 25.11. For later releases,
see the [shipdist releases](https://github.com/ShipSoft/shipdist/releases)
and the [shipdist CHANGELOG](https://github.com/ShipSoft/shipdist/blob/main/CHANGELOG.md).
Each release is still set up with `source /cvmfs/ship.cern.ch/<release>/setUp.sh`.
